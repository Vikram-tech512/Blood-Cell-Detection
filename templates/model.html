Inference Pipeline Specification

End-to-End Pipeline
1. Input Preprocessing: 100x Oil immersion smear image → RGB conversion → 224 × 224 bicubic interpolation → MobileNetV2 channel scaling [-1.0, 1.0].
2. Feature Extraction: 9 Conv2D stages with kernel depths [128 → 256 → 512], interspersed with BatchNormalization and MaxPooling2D.
3. Classification Head: Flatten (4608 features) → Dense (1024) → Dropout (0.5) → Dense (1024) → Softmax (4 classes).
4. Explainable AI: Layer-by-layer GradientTape extraction on conv2d_8 produces 6 × 6 activation map, upscaled to specimen dimensions via JET colormap.
