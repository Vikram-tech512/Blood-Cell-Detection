POST /api/predict
Inference + Grad-CAM + Morphology

Accepts multipart form-data image upload. Computes deep neural classification, class probabilities, Grad-CAM attention heatmap URLs, and quantitative cytological biomarkers.

Request Example (cURL):

curl -X POST http://localhost:5000/api/predict \
  -F "file=@specimen_cell.jpg"

Sample Response (JSON):

POST /api/morphology
Computer Vision Cytometry

Extracts quantitative biological markers without running neural network inference. Useful for rapid cellular geometry and staining profiling.

curl -X POST http://localhost:5000/api/morphology -F "file=@cell.jpg"
