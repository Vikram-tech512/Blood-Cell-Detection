# Security Policy

## Supported Versions
Security updates are actively applied to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
If you discover a potential security vulnerability within this repository, please do **not** disclose it publicly via GitHub issues.

Instead, please report vulnerabilities by creating a Private Security Advisory via GitHub's Security tab or contacting the project maintainers directly. You will receive an initial response within 48 hours.
